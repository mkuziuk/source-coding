# Внешние источники

Все заимствованные фрагменты получены от Claude.

## Код

Фрагменты в коде отмечены комментариями начала и конца.

### source.py

- Строки 30-58: функции `parse_section` и `parse_distribution`.
  Назначение: проверка описания источника и перевод вероятностей в `Fraction`.
  Claude упростил мою первую версию проверки (`verify_input`).
- Строки 119-138: начало функции `main`.
  Назначение: разбор аргументов командной строки, чтение файла, сообщения об ошибках.

### source_extended.py

- Строки 36-140: методы `parse_basic`, `parse_markov`, `parse_mixture`
  и функции `parse_section`, `parse_distribution`, `parse_context`.
  Назначение: разбор и проверка исходного и расширенного формата.
- Строки 272-292: начало функции `main`.
  Назначение: то же, что в `source.py`.

### uniform_coding.py

- Строки 61-103: функция `p_e`, быстрая версия.
  Назначение: вычисление P_e(n) через типы блоков в точной целочисленной арифметике.
- Строки 108-118: начало функции `write_code`.
  Назначение: заголовок файла с описанием кода.
- Строки 183-219: начало функции `main`.
  Назначение: разбор аргументов командной строки, проверка параметров, сообщения об ошибках.

### archiver.py

- Строки 14-38: функции `make_crc_table` и `crc32`.
  Назначение: контрольная сумма CRC32. Использовать CRC32 предложил Claude и помог реализовать и https://www.siliconchipcookies.com/p/implementing-crc32-in-python разобраться.
- Строки 100-155: функция `decompress`.
  распаковка и обработка ошибок.
- Строки 180-187: разбор аргументов командной строки в функции `main`.

### run.sh

- Весь файл сгенерирован Claude.
  Назначение: скрипт запуска программы.

### README

- Claude перенёс основные команды.
